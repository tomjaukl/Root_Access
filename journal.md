Started building the core desktop environment today. Got the basic window component working with useRef, simpler than expected once it clicked. Spent some time debating whether windows should be constrained to the desktop boundaries. Ended up going with the Windows-style approach where they can be dragged freely, since that felt more natural. Resizability turned out to be a non-issue. CSS has a built-in resize-both property that handles it natively. Sometimes the browser just does the work for you.
